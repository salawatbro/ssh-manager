01

Hozir mavjud imkoniyatlar

Yetti blok. Har biri kod bilan tasdiqlangan — CHANGELOG.md, internal/service/ va frontend/src/ asosida.

01 · connections

Ulanish va autentifikatsiya

  • Server CRUD — yaratish, tahrirlash, nusxalash, o'chirish; guruh, muhit (prod / staging / dev), teg, izoh.
  • Uch auth usuli — parol, private key (+ passphrase), tizim ssh-agent; kalitlar ~/.ssh dan avto-aniqlanadi.
  • Secret'lar Keychain'da — parol/passphrase/TOTP faqat macOS Keychain'da (uz.salawat.sshmgr), DB va export'da hech qachon yo'q.
  • Host-key TOFU — o'z known_hosts; o'zgargan yoki @revoked kalit bloklanadi.
  • Jump host — ProxyJump zanjiri; har hop'ning host-key'i tekshiriladi.
  • TOTP / 2FA — keyboard-interactive kod avto-to'ldiriladi, qo'lda kiritish fallback'i bor; + jonli Authenticator paneli.
  • Test connection — forma ichida natija bilan; Quick connect — ⌘K ga user@host:port yozib Enter.
02 · terminal

Terminal

  • Haqiqiy PTY SSH ustida, xterm.js (Canvas renderer) bilan chiziladi.
  • Tab + split pane — gorizontal/vertikal bo'lish, pane daraxti, fokus ring.
  • Tartiblangan oqim — term:data event'lari seq bo'yicha qayta tartiblanadi (kadr yo'qolmaydi).
  • Find (⌘F), tanlaganda avto-nusxa, o'ng-tugma / ⌘V paste.
  • Reconnect — uzilgan sessiya scrollback'ni saqlaydi va bir bosishda qayta ulanadi.
  • Shell integration (OSC 133) — prompt / buyruq / chiqish ajratiladi: gutter chizig'i, yiqilgan buyruqda qizil belgi, davomiylik, ⌘↑/⌘↓ bilan sakrash.
  • Jonli sozlama — font o'lchami, kursor turi/blink, scrollback ochiq terminallarga darhol qo'llanadi.
03 · tunnels & workflow

Tunnel va ish oqimi

  • Port forwarding — local (-L), remote (-R), dinamik (-D, SOCKS5); server o'chirilsa tunnel'lari to'xtatiladi.
  • Jonli status — forward:status event'i orqali start/stop va xato holati.
  • Production guard — prod tegli serverda xavfli buyruqni tasdiqlash so'raladi. Ergonomik to'siq, xavfsizlik nazorati emas.
  • Broadcast — ⇧↵ bilan bir matn tabdagi barcha panel'ga; guard fan-out bilan.
  • Snippets — global / guruh / server ko'lamli buyruqlar, ⌘E palitrasi yoki ⌘⇧1–9 slotlari.
04 · files

SFTP fayl almashinuvi

  • Ikki panelli brauzer — lokal ↔ remote, cgo-siz internal/sftpx ustida.
  • Fayl va rekursiv papka yuklash/tushirish — drag yoki o'ng-tugma, jonli progress va cancel.
  • Remote amallar — mkdir, delete, rename; ustiga yozishda tasdiq.
  • Xavfsizlik — download'da path-traversal to'sig'i, symlink'ni kuzatmaydigan Lstat, oldingi sessiyani yopish (conn leak yo'q).
05 · productivity

Unumdorlik va UI

  • Command palette (⌘K) — Fuse.js fuzzy qidiruv, oxirgi ishlatilish bo'yicha tartib.
  • Sidebar 2.0 — jonli fuzzy filter (nom/host/user/guruh/teg), teg chiplari (any-of), yopiladigan guruhlar (holati saqlanadi), guruh ichida drag bilan tartiblash.
  • Global hotkey (⌘⇧S) — ilova fonda bo'lsa ham oynani ko'rsatish/yashirish.
  • Menu-bar tray — ≤5 pin qilingan serverga tray'dan ulanish; oynani yopish ilovani o'chirmaydi, sessiyalar tirik qoladi.
  • Toast tizimi, hamma joyda native o'ng-tugma menyulari, birinchi ishga tushirish turi, jonli status bar (auth, target, o'lcham, tunnel soni, uptime).
06 · data & settings

Ma'lumot va sozlamalar

  • ~/.ssh/config import — har bir host uchun preview (import qilingani va sababi bilan tashlab ketilgani), ProxyJump nom bo'yicha bog'lanadi.
  • Data vositalari — serverlarni JSON'ga export/import (secret'siz), WAL-xavfsiz DB backup, papkani Finder'da ochish.
  • To'liq Settings — General (login'da ishga tushish, tray'da qolish, chiqishda tasdiq, connect timeout), Terminal, Shortcuts (faqat o'qish), Data, About. Sozlamalar DB'da, kirishda Sanitise() bilan chegaralanadi.
  • Self-uninstall — yozib-tasdiqlash bilan: barcha data, Keychain secret'lari, login-item o'chadi, ilova Trash'ga ketadi. ~/.ssh tegilmaydi.
